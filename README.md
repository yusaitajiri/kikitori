**日本語** · [English](README.en.md)

会議・講義・動画の音声を、**PCの中だけで**リアルタイムに文字起こしする Windows アプリです。
Zoom や Teams などのアプリの音声とマイクを聞き分けて「相手」「自分」に分け、スクショも文字起こしの流れの中に入れられます。
終わったら Markdown・PDF で保存したり、「Agent用にコピー」で AI に要約を頼んだりできます。

- 音声はインターネットに送られません（文字起こしは Whisper をPC上で動かしています）
- 対応: Windows 11（64ビット）。Windows 10 22H2 でも動きますが、アプリ単位の録音は使えず「システム全体」かマイクでの録音になります
- 空き容量: モデル 1 つにつき 200 MB〜1.1 GB（標準モデルは約 570 MB）
- 表示言語: 日本語の Windows では日本語、それ以外では英語で始まります（**設定 → 一般 → 表示言語** で変えられます）

## インストール

1. [Releases](../../releases/latest) から `Kikitori_x.y.z_x64-setup.exe` をダウンロードします。
   - ブラウザが「一般的にダウンロードされていません」などと警告したら、「…」メニューから **保持する** を選びます。
2. ダウンロードしたファイルを開きます。
3. 青い画面「**Windows によって PC が保護されました**」が出たら、**詳細情報** をクリックし、**実行** を押します。
   - まだコード署名をしていないため表示されます。Kikitori は署名がないだけで、PCの設定を変えたり管理者権限を求めたりはしません。
4. インストーラーの指示に従います。管理者権限は不要です（自分のユーザーにだけインストールされます）。

## はじめて使うとき

起動するとセットアップが始まります。

1. **モデルを選ぶ**: PCに合うモデルが選ばれています。そのままで大丈夫です。
2. **ダウンロード**: 初回だけモデルをダウンロードします（標準で約 570 MB）。途中で止まっても続きから再開します。
3. **マイクのテスト**: 10秒ほど話して、言葉が表示されれば準備完了です。
4. **ショートカット**: 最初はオフです。使うときは **設定 → ショートカット** でキーを割り当てます。

## 使い方

| やりたいこと | 操作 |
| --- | --- |
| 録音を始める・止める | **開始** / **停止** |
| 何の音を文字にするか選ぶ | **ソース**: アプリ（Zoom など）、システム全体、マイクだけ。「会話として録音」をオンにすると、自分の声も「自分」として入ります |
| 録音中にソースを変える | 録音画面の上のソース（小さいウィンドウではタイトルバーの **録音中**）から選び直すと、止めずに切り替わります |
| スクショを入れる | 録音中に **スクショ** ボタン。横の **⌄** で撮るもの（アプリのウィンドウ、画面、ほかのウィンドウ）を選べます |
| 話題や場面の区切りを入れる | 録音中に **はさみ** ボタン。書き出しでは区切りごとに見出しが付きます |
| 大事な発言に印を付ける | 録音中に **星** ボタン（いま話している行に付きます）。行の星からも付け外しでき、書き出しでは ★ が付きます |
| 文字起こしを使う | **コピー**、**書き出し**（Markdown〔フォルダか ZIP〕・PDF・Typst）。⋯ メニューに「Markdownでコピー」「Agent用にコピー」 |
| 前の記録を見る | タイトルバーの **履歴**。行の修正や削除もできます |
| 記録をプロジェクトにまとめる | 録音のタイトル横の四角、記録の見出し、履歴の ⋯ や **選択** からプロジェクトを選びます。履歴はプロジェクトで絞り込め、**設定 → プロジェクト** で名前と色を変えられます |

- 記録は `ドキュメント\Kikitori` に、日付とタイトルのフォルダーごとに自動保存されます（`transcript.md` と画像）。
- スピーカーで聞いていると「相手」の声をマイクが拾うことがあります。ヘッドホンがおすすめです（重複した行は自動で消します）。
- 開始/停止、スクショ、重要の印、区切りには、**設定 → ショートカット** でどの画面からでも使えるキーを割り当てられます（最初はオフ）。
- GPU が使えないPCでは自動で CPU で動きます。遅いと感じたら **設定 → モデル** で「軽量」を選んでください。

## プライバシー

- 音声はPCの外に出ません。録音した音声は文字にしたあと破棄され、保存もされません。
- ネットワークを使うのはモデルのダウンロード（huggingface.co）と、1日1回のアップデート確認（GitHub）のみ。
- 利用状況の送信（テレメトリー）はありません。

## 困ったとき

- **アプリの音が入らない**: ソースを「システム全体」に切り替えてください（アプリが音声を出していないと、アプリ単位では録れません）。
- **ショートカットが効かない**: 管理者として実行中のアプリが前面にあると、Windows の仕様で届きません。
- **ログ**: **設定** の一番下の「ログを開く」。ログに文字起こしの内容は書かれません。
- **アンインストール**: Windows の 設定 → アプリ → インストールされているアプリ → Kikitori。記録（`ドキュメント\Kikitori`）は残ります。
